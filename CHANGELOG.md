## 1.23.0 — 08 Aug 2026 04:30:00 +0200

- i18n/: translations of the human-facing documents (README.md, docs/GUIDE.md, docs/MANUEL.md) into French, German and Spanish. English stays canonical and stays in place; nothing was moved. The tree is asymmetric on purpose: docs/GUIDE_LLM.md and its three notices are never translated. Their paths are frozen (guide-lock, debian/diwall.install, deploy.sh, runtime error messages, partner documentation), and a translated locked guide can silently desynchronise -- a version number mechanically resynchronised over stale content would let an agent pass the lock having read obsolete instructions, the exact failure the lock exists to prevent.
- i18n/manifeste.json: the pedagogical order of the documents, declared once for every language. Translations inherit it, they never redeclare it -- otherwise four PDFs end up with three different orders and nobody notices until a Spanish reader uninstalls before installing. Every file in the declared perimeter must appear in either the order or the motivated exclusions; a file in neither fails the build.
- scripts/i18n/generer-pdf.py: one reference PDF per language, table of contents generated by pandoc from the merged headings (--toc), never maintained by hand. Only the order is declared. An implicit order (alphabetical, or whatever the filesystem returns) is never the pedagogical order -- a Sillage manual once listed reinstallation before installation for exactly that reason.
- scripts/i18n/traduire.py: segment-by-segment translation. Each translated segment is stored next to its source fingerprint, so fixing a typo retranslates the touched segments only, not four complete documents. Protected zones (fenced blocks, inline code, paths, long options, URLs, anchor targets, JSON keys) are replaced by opaque tags before the call and restored after it: what must not be translated never reaches the model. Asking a model not to translate --wait-until works most of the time, and "most of the time" produces a broken command nobody finds.
- The tag check is purely mechanical -- same count, intact, no duplicates -- and rejects the segment to human arbitration on any divergence, with the English source kept in the output. Two further mechanical checks earn their place from measured failures: a segment handed back unchanged is rejected (the similarity gate is structurally blind to it, an untranslated segment back-translates to itself and scores a perfect 1.0), and the placeholder instruction is sent only when the segment actually holds placeholders (mentioning them otherwise makes the model invent some: 19 of 21 rejections on README.md, before the fix).
- Two further checks, both added after seeing the failure on a real three-language run. The model sometimes answered the instruction instead of following it, prefixing its output with the instruction translated -- 89 segments across French and Spanish, tags intact, no length anomaly on long segments. It is caught by a literal: the instruction describes the tag shape as [[[xxx]]] and real tags are numeric, so that string can only arrive one way. And from the single heading "## Uninstalling Diwall" the German run invented a complete Windows uninstall procedure, caught only because it happened to mention /usr/local. Hence a length-ratio check: translation stretches text by tens of percent, never by a factor of ten.
- Tag numbering stays sequential. Opaque identifiers were tried, on the theory that a numbering offers an obvious next term to invent, and scored 9/10 against 1/10 on a ten-segment sample -- but that sample was built from segments that had failed under sequential tags, which cannot answer the question. On 40 randomly drawn segments the ranking inverted: sequential 39/40 accepted first try, opaque 34/40.
- scripts/i18n/verifier-traduction.py: two independent nets. Options and paths are compared source-to-translation over the whole document, independently of the tag mechanism -- two nets that fail for different reasons beat one very careful net. Then a similarity gate (back-translation by a fresh call, cosine similarity over local nomic-embed-text embeddings), entirely switchable off, and never applied to positioning text: cosine similarity measures drift of meaning, not drift of register, and a faithful translation slid into a promotional register would clear the threshold unnoticed.
- i18n/<language>/arbitrages.json: human-settled translations, keyed by source fingerprint and consulted before the automatic cache, so a stale machine translation can never outrank a human decision. Rejection now has a destination instead of only a report: keeping the English source is right for a pipeline and wrong for a deliverable, and hand-fixing the output would not survive the next --forcer. All 100 pending segments are settled; the three languages build with none awaiting arbitration. An arbitration may also target a fenced block, which only a human can decide: some blocks are ASCII diagrams whose content is prose, not code.
- Both remaining nets fired on hand-written arbitrations, which is the point of nets that do not depend on the model. The second net caught a Spanish segment where plugins/languages/platform had been translated -- those are navigator.* property names, and masking had been protecting the model from exactly that. Its path pattern also stopped swallowing a sentence's closing full stop, which had produced a phantom divergence.

Segment-by-segment translation has no memory: each call sees one paragraph and nothing else.
- The instruction is not sent by default, which is measured rather than assumed. On 30 randomly drawn segments: no register instruction 28/30 accepted first try, a one-line instruction 20/30, the instruction plus six imposed terms 13/30. translategemma is built for translation, not for instruction-following. The instruction is now paid only where needed -- a segment returned in the familiar register is retried with it -- and imposed terminology left the prompt entirely.
- Completeness check, and it is the one that mattered most. A rejected segment keeps its English source, so a document can be half English while every other net stays green: paths and options are identical by construction, and English holds no familiar-register word either. The over-long prompt above pushed Spanish to 165 rejections of 345 -- 48% of the document in English, every other net reporting OK. verifier-traduction.py now checks completeness first and fails on any segment still carrying its source.

Three departures from the Sillage original: hyphenation stays on (German compounds), polyglossia is not hardcoded to French (one preamble, four languages), and cell padding drops from 14pt to 4pt (wide reference tables). Motivated by a real target — a router administration panel polling live statistics, where the 500 ms of network silence networkidle requires never occurs, so no --timeout value could ever succeed. Applies to the initial navigation only; the naviguer action is untouched. boussole.wait_until reports the value only when it differs from the default, never the bare CLI flag (same discipline as stealth_actif, fixed in v1.16.0). Propagated by rpa.py to its shot.py subprocess, and available as a root wait_until property on a scenario (CLI flag wins over the property): without that, the flag would only have served direct reconnaissance, while the target that motivated it is administered by scenario.

One page documents all six, git(1)-style — seven pages would drift out of sync with --help, one has a single source of truth. Generated at build time by pandoc from debian/diwall.1.md, so it cannot go stale by omission; man diwall-shot and the five other names resolve to it via .so aliases.
